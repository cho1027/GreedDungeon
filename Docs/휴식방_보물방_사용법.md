# 휴식방과 보물방

## 실행

Main 씬의 Generator > Special Rooms에 Rest와 Treasure를 각각 1개 추가했습니다.
기존 방 설정은 유지했습니다. Play 후 미니맵의 휴식·보물방을 찾아 입장합니다.
방 입장 트리거가 전용 검은 화면을 열고 기존 RoomTransitionController가 화면을 닫을 때까지 입력을 잠급니다.
버튼은 기존 EventSystem을 사용합니다. 별도 패키지 설치는 필요 없습니다.

- 휴식방: 불 붙이기 → 회복 또는 강화 → 던전으로 돌아가기.
- 회복: 최대 체력의 30%, 소수점은 0.5 이상 올림. 최대 체력이면 실제 회복 0이며 선택은 소비됩니다.
- 강화: 플레이어에 IRestRoomUpgrade를 구현한 컴포넌트를 붙이면 연결됩니다. TryUpgrade 성공 시만 소비합니다.
  현재 강화 효과는 없으며 안내 후 회복을 선택할 수 있습니다.
- 보물방: 현재는 상자 개봉과 재방문 상태만 확인합니다. 실제 유물 콘텐츠는 없으며 보상을 지급하지 않습니다.
  향후 Relic Pool에 데이터를 연결하면 세 유물 중 하나를 선택하는 구조를 사용할 수 있습니다.
- 선택 전 나가기도 가능합니다. 재입장하면 점화/개봉 상태와 같은 후보가 유지됩니다.
- 사용 완료 방에 재입장하면 결과만 표시합니다.

## Inspector

Assets/RoomFeatures에 전용 RoomData, 방 프리팹, 화면 트리거와 개발용 유물 3개가 있습니다.

RestScreen:
- Campfire Lit: 제공한 Campfire_lit.png가 연결되어 있습니다.
- Campfire Unlit: 원본을 참조해 AI로 제작한 Campfire_unlit.png가 연결되어 있습니다.
- Font: 기존 Ultimate_Font를 재사용합니다.

TreasureScreen:
- Chest Open: Assets/Image/opened_treasure.png가 연결되어 있습니다.
- Chest Closed: 열린 원본을 참조해 AI로 제작한 Assets/Image/closed_treasure.png가 연결되어 있습니다. 개봉 버튼을 누르면 Chest Open 이미지로 전환됩니다.
- Relic Pool: 현재 빈 목록입니다. 아직 실제 유물을 만들지 않는 기획을 반영했습니다.
  추후 서로 다른 ID의 유물 3개 이상을 연결하면 후보는 첫 개봉 시 확정됩니다.
- Development Mode: 꺼져 있습니다. TestRelic1~3은 기존 검증용 파일로만 남아 있으며 게임에서는 사용하지 않습니다.
- 모든 이미지는 원본 종횡비를 유지하며 화면 중앙의 같은 영역에 표시됩니다.

RelicData는 Create > GridDungeon > Relic으로 만듭니다.
ID는 유물마다 다르게 지정하세요. 이름·설명·아이콘·등급·효과 유형·효과 수치를 보관하지만 효과는 적용하지 않습니다.
획득 여부는 공유 ScriptableObject에 쓰지 않고 RoomRunData.Relics.OwnedIds에 저장합니다.
현재 중복 ID 획득은 금지되어 있습니다.

## 상태 보존 범위

RoomRunData는 런 ID + 씬 경로 + 방 MapCell을 고유 키로 사용합니다.
현재 런의 기록은 일반 씬 로드에도 유지됩니다. 새 던전 Generate는 새 런으로 취급하고 전부 초기화합니다.
단순히 다른 층을 생성하며 기록을 유지하려면 추후 Generate의 BeginNewRun 호출을 새 게임 시작 지점으로 옮겨야 합니다.
앱 종료 후 복원하는 디스크 세이브는 기존 시스템이 없어 구현하지 않았습니다.

## 검증

Tools > Grid Dungeon > Validate Special Rooms는 임시 오브젝트로 규칙을 검사합니다.
Play를 끈 상태에서 실행하세요. Play 중에는 현재 런 기록을 보호하기 위해 실행을 차단합니다.
검사: 점화 전 차단, 30% 회복, 최대 체력 제한, 사망, 중복 수령, 강화 연결과 상호 배제,
후보 중복/부족, 개봉 전 선택, 잘못된 인덱스, 후보 유지, 유물 한 개 지급, 방별 기록, 새 런 초기화.

실제 UI 확인:
1. 휴식방에 들어가 점화 전 버튼과 이미지 상태를 확인합니다.
2. 점화 후 강화 버튼의 미구현 안내와 회복 버튼 동작을 확인합니다.
3. 나갔다 다시 들어가 중복 회복이 불가능한지 확인합니다.
4. 보물방에서 개봉 후 선택 없이 나갔다 돌아와 같은 후보인지 확인합니다.
5. 한 유물을 선택하고 보유 ID 목록과 완료 화면을 확인합니다.
6. 원본 모닥불은 검은 배경이 포함된 이미지이므로 전용 화면에 그대로 표시됩니다.
